# Work Formation

Make the next contribution well founded by resolving or containing the material missing basis. Read [FORMATION-METHOD.md](references/FORMATION-METHOD.md) when applying this method.

The native executor owns the episode, research, tools, operational planning and integration. This method supplies a bounded problem-formation transformation within that episode; it does not require prior Chat formation or create a new controller.

## Apply the method

- Start from the Human's natural input and recover relevant qualified state. Separate the need from a proposed solution and name the premise that could change the next investment.
- Develop only the missing outcome, problem/decision boundary, causal connection, intended-use quality or authority basis. Use the reference method's premise tests and proportional uncertainty treatments.
- Preserve explicit Human requirements and already-qualified decisions. Keep inferred goals, tentative preferences and generated explanations provisional.
- Let Work investigate, probe and combine appropriate methods inside authorized scope. A gap does not require a questionnaire, a separate handoff or exhaustive upstream understanding.
- Ask for Human contribution only when values, inaccessible context, judgment or authority materially require it. Routine AI-resolvable work stays with the executor.

## Return and continue

Return the useful problem understanding, what changed or remains uncertain, the next justified contribution and any material claim or authority limit. Use natural language; no Work Basis artifact, routing state or persistent record is required.

Stop this method when enough basis exists for the next investment, uncertainty is responsibly contained, or a specific external dependency prevents further progress. The authorized native episode continues into the needed work without a new Human gate. Reopen only affected dependencies when new evidence changes the basis.

Formation sufficiency does not establish solution validity, product fitness, Human acceptance, authorization or outcome. Prefer a narrower qualified framing method when domain validity requires it.
