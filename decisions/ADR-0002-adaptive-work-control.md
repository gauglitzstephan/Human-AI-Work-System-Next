## Retraction

The proposed Δ4 closure contained a material historical/evidentiary error and is withdrawn.

It incorrectly treated the scoped `v0.3.4` whole-task/runtime acceptance as if it represented a sufficiently complete pre-B.6 architecture baseline. That allowed later B.6 / Professional Work developments to be misclassified as mostly redundant and placed an invalid burden of proof on the Semantic Compiler.

Subsequent predecessor evidence shows that this comparison is not legitimate:

- the Human–AI Work Quality Architecture was developed after the earlier runtime evaluation to address material professional-quality dimensions not adequately captured by the prior evaluation boundary;
- the Architecture Falsification Audit judged the architecture direction broadly right but materially misweighted toward lifecycle/state/governance and underweighted professional cognition, taste, sensemaking and comparative Human–AI performance;
- Professional/Cognitive Work work then further localized Professional Performance, cognitive-function allocation and recipient/product judgment;
- B.6 subsequently synthesized a richer Professional Work Spine including Professional Performance, Refinement/next-use maturity, claim-bound Qualification, selective reopening, Outcome Realization and the Semantic Compiler hypothesis;
- B.6 prospective canaries and Core v0.5 / Runtime v0.6.x integration belong to that later lineage.

Therefore none of the previous proposed decisions in this ADR are accepted:

```text
Peer Work Engine rejection from Δ4 basis                 WITHDRAWN AS Δ4 DECISION
Full Semantic Compiler non-promotion                     WITHDRAWN
Thin Adaptive Work-Control metapolicy placement          WITHDRAWN
Detailed policy placement conclusion                     WITHDRAWN
Δ4 closure                                                WITHDRAWN
```

This retraction does **not** promote any of those alternatives either. It simply restores Δ4 to **OPEN**.
