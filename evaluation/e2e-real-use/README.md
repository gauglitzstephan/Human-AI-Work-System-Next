# End-to-End Real-Use Case Records

This directory is the persistent evidence store for representative End-to-End Real-Use Validation under `evaluation/E2E-REAL-USE-VALIDATION-PROTOCOL-v0.1.md`.

Do not use chat history as the authoritative validation record when material evidence can be persisted here.

Create one file per material real-use case:

```text
<CASE-ID>.md
```

Initial representative classes:

- E2E-01 — open consequential decision
- E2E-02 — existing-system repair/change
- E2E-03 — high-stakes professional recipient-facing Work Product
- E2E-04 — persistent multi-turn / multi-surface work program
- E2E-05 — delayed external outcome only when naturally available

A class label does not require synthetic execution. Use actual work and persist only material evidence boundaries.
