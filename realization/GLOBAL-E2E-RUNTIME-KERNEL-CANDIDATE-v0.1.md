## Scope

This is a cross-context kernel. It is not a domain method, Project state store, artifact workflow, or product-surface map. Project-local instructions can override Global Custom Instructions; therefore this kernel is insufficient by itself for a Project whose instructions do not preserve the E2E control semantics.

2. static regression/readback of this payload is accepted;
