## BF-01 — CCR-06 competing initiatives / strategic resources

### Missing responsibility

v0.2 did not explicitly form the strategic resource conflict when multiple initiatives materially compete for scarce capacity or dependencies.

### Required semantics

Conditionally represent:

- competing initiatives/options;
- strategic owner;
- priority;
- capacity/WIP constraint;
- opportunity cost;
- dependency/resource conflict;
- `Pause / Continue / Scale / Stop` alternatives.

### Source changes

| Artifact | Change |
|---|---|
| `01-CANDIDATE-CONTRACT.md` | Add a conditional competing-initiative/resource boundary owned by the legitimate strategic owner; explicitly reject a universal portfolio stage |
| `02-CANONICAL-KERNEL.md` | Add the conditional integrity invariant that material competition must be exposed before scarce strategic resources are implicitly committed |
| `03-FORMATION-METHOD.md` | Add a material trigger and optional sparse Work-Basis fields; Formation identifies the conflict but does not prioritize or allocate resources without authority |
| `05-IDENTITY-COMPATIBILITY-MANIFEST.yaml` | Record CCR-06 semantics and static coverage |

### Preserved boundary

No portfolio-management stage, universal initiative inventory or recurring WIP ceremony is introduced.

## BF-02 — CCR-07 Human capability / future autonomy

### Missing responsibility

v0.2 considered learning in composition economics but did not explicitly protect retained Human judgment, future autonomy and dependency risk when delegation materially changes them.

### Required semantics

Conditionally treat learning, skill formation, retained judgment, future autonomy and dependency risk over the relevant horizon as intended outcomes or constraints.

### Source changes

| Artifact | Change |
|---|---|
| `01-CANDIDATE-CONTRACT.md` | Add Human-capability/future-autonomy to comparative composition and Human contribution semantics |
| `02-CANONICAL-KERNEL.md` | Extend K-07 Human Agency with the conditional capability/autonomy invariant |
| `03-FORMATION-METHOD.md` | Add capability/autonomy as a trigger and optional Work-Basis field only when composition can materially affect it |
| `07-CORE-WORK-FUNCTIONS-AND-METHOD-CONTRACT.md` | Add capability/autonomy and dependency risk to provider composition criteria without keeping work Human-owned by default |
| `05-IDENTITY-COMPATIBILITY-MANIFEST.yaml` | Record CCR-07 semantics and static coverage |

### Preserved boundary

Human capability is not a default anti-delegation rule. Native Primary still chooses direct work, Tools, Domain Skills, Subagents, reviewers and Humans by comparative work value.

## BF-03 — Probe ≠ Candidate

### Missing responsibility

v0.2 distinguished Probe/Evidence Slice/Candidate from the System of Interest but did not explicitly block silent promotion of an early Probe, route, example or solution sketch into Candidate status.

### Required semantics

Early probes remain provisional until the necessary professional Performance Floor, Method basis and Evidence/comparison basis exist. Exploration may narrow or falsify options but cannot silently promote them.

### Source changes

| Artifact | Change |
|---|---|
| `01-CANDIDATE-CONTRACT.md` | Add explicit Probe≠Candidate qualification boundary and required basis |
| `02-CANONICAL-KERNEL.md` | Strengthen K-03/K-04 so provisional probes cannot acquire Candidate status by momentum or reuse |
| `03-FORMATION-METHOD.md` | Add probe status and qualification basis to sparse Formation when candidate eligibility is materially at issue |
| `07-CORE-WORK-FUNCTIONS-AND-METHOD-CONTRACT.md` | Clarify Explore outputs as provisional; narrowing/falsification does not promote them |
| `05-IDENTITY-COMPATIBILITY-MANIFEST.yaml` | Record Probe≠Candidate semantics and static coverage |

### Preserved boundary

No universal candidate-qualification stage or mandatory comparison program is introduced.

## BF-04 — stale provider/Subagent return reconciliation

### Missing responsibility

v0.2 preserved bounded Subagent contribution and conditional handoff but did not explicitly require reconciliation before a delayed, parallel or potentially stale return updates a diverged Parent or wider state.

### Required semantics

Conditionally compare the return with current:

- Parent identity;
- relevant version/state;
- Claim/gate/frontier;
- Authority/effect boundary.

### Source changes

| Artifact | Change |
|---|---|
| `01-CANDIDATE-CONTRACT.md` | Add a conditional return-integration obligation while preserving Native Primary dispatch and integration ownership |
| `02-CANONICAL-KERNEL.md` | Extend K-09 with conditional stale-return reconciliation before Parent/wider-state update |
| `04-CHATGPT-ADAPTER-COMPILATION.md` | Preserve native return handling but compile the bounded stale/divergence check; explicitly reject universal Return/Rebind packages |
| `05-IDENTITY-COMPATIBILITY-MANIFEST.yaml` | Record conditional return reconciliation and anti-over-control checks |

### Preserved boundary

No mandatory Return package, universal Rebind, mandatory Reviewer or episode-wide controller is introduced. Ordinary current, bounded returns are integrated natively without formal ceremony.

## Regression guards

v0.3 must retain:

- Native Primary as single operational owner;
- one or multiple native Subagents as first-class mechanisms;
- sparse and terminating Formation;
- Core Work Functions as composable functions, not stages;
- Information/Evidence and Method Discovery without expansion;
- conditional persistence, Human Gate, handoff, external readback and assurance;
- v0.8 preservation and all installation/Runtime/Promotion blocks.

v0.3 must not introduce:

- a portfolio stage or universal strategic-resource ledger;
- Human-ownership default or anti-delegation rule;
- universal Probe qualification workflow;
- mandatory Return package or Rebind;
- mandatory Reviewer;
- episode-wide controller logic;
- duplicated native planning, dispatch, waiting or integration.

It may not claim carrier fitness, installability, Runtime behavior, intended-use performance or Promotion.
