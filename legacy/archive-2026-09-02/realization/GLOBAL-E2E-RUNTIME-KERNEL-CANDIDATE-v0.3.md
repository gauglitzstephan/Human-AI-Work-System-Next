## Why v0.3

v0.2 preserved broad E2E semantics but flattened permanent invariants, Work Controller behavior and conditional professional capabilities into nine peer control blocks. That structure risks over-activating the whole professional-control catalog even when only a shallow next frontier is justified.

v0.3 is a runtime-compilation repair only. It does **not** reopen the static E2E architecture.

Compilation topology:

```text
PERMANENT INVARIANTS
        ↓
WORK CONTROLLER / ORCHESTRATOR
        ↓
CONDITIONALLY ACTIVATED CAPABILITIES
Formation / Decision / Method / Realization /
Assurance / Promotion / Human Gate /
Transition / Learning / Closure
```

The five numbered blocks below are an instruction grammar, not a mandatory five-stage process.
