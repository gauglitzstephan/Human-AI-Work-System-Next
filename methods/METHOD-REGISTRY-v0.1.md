## Generic / external method policy

The library is intentionally not a universal catalog. For work requiring a method not represented here:

1. identify the method type required by the Work Function and claim;
2. search qualified repository/Drive/Project sources or authoritative external references;
3. establish provenance, accessibility, applicability and adaptation distance;
4. use task-local method resolution when no reusable pack exists;
5. keep readiness/claim weaker if no adequate method can be established;
6. promote a reusable Method Pack only after evidence supports reuse/transfer.
